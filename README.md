# NestedSSR

A unified framework and R simulation platform for blinded sample size
re-estimation (SSR) in balanced and unbalanced nested designs.

## Overview

This repository contains R programs accompanying the manuscript

> Adjusted Blinded Variance Estimation for Sample Size Re-estimation
> in Nested Designs

The proposed methodology develops blinded variance estimators for:

- Balanced fixed-effects nested designs
- Balanced random-effects nested designs
- Unbalanced fixed-effects nested designs
- Unbalanced random-effects nested designs

using exact noncentral F-based inference.
